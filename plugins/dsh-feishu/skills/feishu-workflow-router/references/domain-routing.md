# 飞书领域路由索引

先运行 `lark-cli skills list`，再用本索引匹配请求与**当前列出的**技能，最后读取该技能。下表第一列是选择器键，第二列是匹配语义；两者都不是硬编码的命令或技能名。

| Domain | 匹配语义 |
| --- | --- |
| docs | 云文档 Docx：选择当前文档覆盖云文档读写的技能。 |
| wiki | 知识库：选择当前文档覆盖 Wiki 空间或节点的技能。 |
| drive | 云空间：选择当前文档覆盖云盘文件、文件夹、权限的技能。 |
| sheets | 电子表格：选择当前文档覆盖 Sheets 的技能。 |
| base | 多维表格 Bitable：选择当前文档覆盖 Base 记录、字段、视图、仪表盘的技能。 |
| slides | 幻灯片：选择当前文档覆盖 Slides 的技能。 |
| whiteboard | 白板：选择当前文档覆盖白板/画板的技能。 |
| markdown | 选择当前文档覆盖 Markdown 与文档互转的技能。 |
| note | 思维笔记：选择当前文档覆盖思维笔记的技能。 |
| im | 消息与群：选择当前文档覆盖会话、消息、群成员、卡片的技能。 |
| mail | 邮箱：选择当前文档覆盖邮件的技能。 |
| calendar | 日历：选择当前文档覆盖日程、忙闲、会议室的技能。 |
| meeting | 会议：从当前 `lark-cli skills list` 里选择会议相关技能并读取；不要用记忆中的旧别名替代。 |
| minutes | 妙记：选择当前文档覆盖妙记/逐字稿/纪要的技能。 |
| vc | 视频会议：选择当前文档覆盖 VC 会议控制的技能。 |
| task | 任务：选择当前文档覆盖任务/待办拆分的技能。 |
| approval | 审批：选择当前文档覆盖审批实例、待办、定义的技能。注意审批待办 ≠ 任务。 |
| attendance | 考勤：选择当前文档覆盖考勤打卡的技能。 |
| okr | 选择当前文档覆盖 OKR 的技能。 |
| contact | 通讯录：选择当前文档覆盖用户/机器人检索的技能。 |
| event | 事件订阅：选择当前文档覆盖事件订阅/回调的技能。 |
| apps | 妙搭 Spark/Miaoda：选择当前文档覆盖妙搭应用开发、部署、日志、环境变量的技能。不要用 Base 的 BaseApp 顶替。 |
| openapi-explorer | 原始 OpenAPI：仅在已读 `lark-shared`、且现有技能确实没有封装该操作时，才用探索型技能走原始接口。 |
| workflow | 复合流程：当安装列表提供会议纪要、站会周报等复合工作流技能时，优先用它们而不是自己拼装多步调用。 |
| skill-maker | 需要按官方约定扩展/生成新技能时使用。 |

若多个技能都看似匹配，比较它们当前的 description，读取资源与操作真正匹配的那个。若都不匹配，先读 `lark-shared`，确认运行时是否提供原始 API 路由；否则直接报告当前安装不暴露受支持的路径。
